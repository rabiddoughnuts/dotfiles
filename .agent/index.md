# Agent File Index

Purpose: List `.agent/` files and their roles in this workspace.
Belongs here: File names and short descriptions.
Does not belong: Detailed task history or troubleshooting notes.

## Files
- `.agent/active-task.md`: Short current-task state for ongoing work.
- `.agent/workspace-map.md`: Concise directory map and working boundaries.
- `.agent/project-compass.md`: Durable workspace direction, constraints, and near-term risks.
- `.agent/issue-log.md`: Recurring failure modes and prevention notes.
- `.agent/plan-tracker.md`: Plan-file lifecycle tracking.
- `.agent/plans/README.md`: Conventions for task-specific plans.
- `.agent/archive/README.md`: Rules for keeping retired notes when they remain useful.
