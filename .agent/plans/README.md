# Plans

Purpose: Hold task-specific plans for substantial multi-step work.
Belongs here: Concrete plans with scope, phases, dependencies, and verification notes.
Does not belong: Policy, permanent workspace metadata, or finished-task diary content.

## Conventions
- Use one file per substantial task.
- Name files `plan-<topic>-YYYY-MM-DD.md`.
- Add each new plan to `.agent/plan-tracker.md`.
- Remove or archive completed plans according to their cleanup intent.
